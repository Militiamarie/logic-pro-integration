Logic Pro Integration

Starter kit for building plug-ins, MIDI tools and controllers that work with Apple Logic Pro — by Melitia Marie Productions.

There is no official public “Logic Pro SDK”. You integrate through Audio Units, Scripter, MIDI and control-surface protocols. See the README for details and links.

Audio Units (AUv3)

Instruments, effects and MIDI FX as app extensions — Mac and iPad. Apple docs

Scripter (JavaScript)

Logic's built-in MIDI FX scripting. Try scripter/melitia-808-humanizer.js. Guide

Control surfaces

Mackie Control, HUI, MIDI Learn, OSC and Logic Remote. Support guide

Adobe SDKs

Creative SDK is retired. Today: Express Embed SDK, UXP, After Effects SDK. Express Embed SDK

// Scripter: pass-through with octave double
function HandleMIDI(event) {
  event.send();
  if (event instanceof Note) {
    event.pitch += 12;
    event.send();
  }
}
